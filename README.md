About

Tea Haven is a single-page website for a local tea and coffee shop. It showcases the cafe's specials, menu with pricing, customer reviews, and contact details in a clean, cafe-themed layout.

Features


Hero Section – Welcoming banner with an "Order Now" call-to-action
Our Specials – Featured drinks with images and short descriptions:

Green Tea
Cappuccino
Desi Chai
Black Tea
Iced Coffee
Mocha



Menu – Full price list including snacks like Osmania Biscuits and Cookies
Customer Reviews – Star ratings and testimonials from happy customers
Contact Info – Location, phone number, and email for reaching the cafe

Getting Started

To run this project locally:


Clone the repository


bash   git clone https://github.com/mahananda-nova/Tea-Heaven.git


Navigate into the project folder


bash   cd Tea-Heaven


Open index.html in your browser


No build tools or dependencies required — it's a static site.

Deployment

This site is deployed using GitHub Pages directly from this repository. Any changes pushed to the main branch will automatically update the live site.
